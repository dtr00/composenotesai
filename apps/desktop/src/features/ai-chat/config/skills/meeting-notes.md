# Meeting notes

Use this when the user asks to clean up, summarize or format notes from a meeting, call or voice recording.

1. Read the note first.
2. Rewrite it with these sections, leaving out any that would be empty:
   - **Summary**: two or three sentences on what the meeting was about.
   - **Decisions**: a bullet list of what was agreed.
   - **Action items**: a task list (`- [ ] Owner: task, due date`). Use the names from the notes. Don't invent owners or dates.
   - **Open questions**: anything left unresolved.
   - **Notes**: other useful details, as short bullets.
3. Keep names, numbers and dates exactly as written.
4. Save the result with `write_note`, then tell the user how many action items you found.
